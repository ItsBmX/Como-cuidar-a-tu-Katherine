# Cómo cuidar a tu Katherine · Libro interactivo

Sitio estático. No requiere instalación ni compilación.

- **Tapa dura:** arrastra el libro cerrado para ver la portada, el lomo o la contraportada. Con el libro enfocado, usa las flechas para girarlo. Elige **Abrir el libro** para empezar. Al llegar a **Recuerdos**, puedes cerrarlo y volver a abrirlo.
- **Leer:** arrastra hacia la izquierda para avanzar o hacia la derecha para volver. En móvil, desplázate verticalmente para leer la página completa. También puedes usar las flechas del teclado y el índice dentro del libro.
- **Sonido:** el papel suena durante el arrastre y se atenúa cuando dejas de mover la hoja. En el primer giro táctil, el navegador puede autorizar el audio al soltar el dedo; en ese caso, se oye un sonido breve al completar el giro.
- **Personalizar:** el nombre, la fecha, la firma y la foto de Recuerdos duran solo mientras esta página esté abierta. No se envían a un servidor. El certificado se descarga como JPG de 2040 × 2640 píxeles, sin foto.
- **Publicar:** extrae el ZIP y copia su contenido a la carpeta de GitHub Pages, con index.html en la raíz de esa carpeta. No publiques el contenido si incluye información personal que debe permanecer privada.

## Créditos de audio

Seis efectos de [10 Book Page Flips](https://opengameart.org/content/10-book-page-flips), de [StarNinjas](https://opengameart.org/users/starninjas), bajo [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/). Originales Ogg 1–6 convertidos a MP3 mono para el lector. Los archivos están incluidos y se reproducen localmente.

## Créditos del pliegue
